# AI Code Reviewer Project - MVP Implementation

## Overview
Building an AI Code Reviewer web application with a modern homepage, theme switching, and navigation structure.

## Files to Create/Modify:

1. **src/components/ThemeProvider.tsx** - Theme context provider for dark/light mode switching
2. **src/pages/HomePage.tsx** - Use this for HomePage component (main landing page)
3. **src/App.tsx** - Update routing and theme provider integration
4. **src/pages/LoginPage.tsx** - Simple login page component
5. **src/pages/SubmitCodePage.tsx** - Code submission page component
6. **index.html** - Update title and meta tags for AI Code Reviewer
7. **package.json** - Add any missing dependencies (lucide-react icons)

## Key Features:
- Responsive homepage with hero section, features, and footer
- Dark/light theme switching
- Navigation between pages (Home, Login, Submit Code)
- Modern UI with Shadcn components and Tailwind CSS
- Mobile-responsive design
